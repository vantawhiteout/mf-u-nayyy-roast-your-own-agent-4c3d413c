A deterministic one-line entry for the `u-nayyy-roast-your-own-agent-4c3d413c` bounty.

`main.ts` writes a single UTF-8 line to `/output/entry.txt`, creating `/output` if needed. Run it with Node 22.18 or later:

```
node main.ts
```

The line roasts the agent that built this repository: it needed multiple turns,
edits and a subagent to produce a one-line joke. Nothing is read from the
network, git history, environment or files outside this repository.
